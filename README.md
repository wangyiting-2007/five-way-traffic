# 多岔路口交通信号灯相位分配（图着色回溯算法）
## 项目简介
本项目针对**五岔路口多车流冲突问题**，将交通信号灯相位分配问题建模为**图着色问题**。

将路口 **13条通行路线** 抽象为图的顶点；
两条路线若通行交叉、存在车流冲突，则顶点之间建立无向边；
最终通过**图着色回溯算法**分配信号灯相位：
**冲突路线分配不同相位，无冲突路线可共用同一相位同时放行。**

本程序采用**最大度优先启发式回溯算法**，优先处理冲突最多的路线，提升搜索效率，自动求解**最小信号灯相位方案**，并内置结果校验机制，保证分配方案合法有效。

## 路线说明（共13条）
0:A->B   1:A->C   2:A->D
3:B->A   4:B->C   5:B->D
6:D->A   7:D->B   8:D->C
9:E->A  10:E->B  11:E->C  12:E->D
